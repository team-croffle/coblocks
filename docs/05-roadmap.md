# 로드맵

현재 상태: 학습자 흐름(랜딩 → 로그인 → 대시보드 → 커리큘럼 → 블록 플레이어)과 관리자 6개 화면이 동작하는 스캐폴드. API는 인증·미션·진도·관리자 엔드포인트가 구현되어 있고, 일부 화면은 API 연결 전 시드 데이터로 폴백한다.

## 1단계 — 실데이터 연결 (먼저 할 것)

- [ ] `apps/web` 의 시드 폴백 제거. `CurriculumPage`, `LessonPlayerPage`, `DashboardPage` 의 `initialData` 를 로딩/에러 상태로 교체
- [ ] `/progress/me/activity` 추가 후 대시보드 '최근 활동' 연결
- [ ] `/inquiries` 공개 엔드포인트 + 학습자 문의 등록 화면
- [ ] 에러 토스트 컴포넌트 (지금은 페이지마다 `notice` 문자열)
- [ ] TanStack Router loader 로 데이터 프리페치 — 지금은 컴포넌트에서 useQuery 로만 가져온다

## 2단계 — 관리자 완성

- [ ] 스테이지 편집기: 격자를 클릭해 벽·시작·목표를 찍고 `StageConfig` 로 저장
- [ ] 마스킹 해제 승인 화면 (`unmask_requests` 승인/거부, 만료 시각 설정)
- [ ] 감사 로그 CSV 내보내기 (내보내기 행위 자체도 감사 로그에 남길 것)
- [ ] 미션 리비전 비교 화면 (`lesson_revisions` diff)

## 3단계 — 학급

- [ ] `classes`, `class_members` 테이블
- [ ] 교사용 학급 진도 화면 (학생별 완료 현황, 개념별 취약 지점)
- [ ] 학급 계정 일괄 생성 (CSV 업로드) — 문의에서 실제로 들어온 요구

## 4단계 — 학습 경험

- [ ] 블록 드래그 앤 드롭 (지금은 클릭으로 추가)
- [ ] 조건 블록(`if / else`)을 인터프리터에 추가 — 스테이지에 센서 개념 필요
- [ ] 블록 ↔ 파이썬 나란히 보기 (중학교 후반 미션의 핵심)
- [ ] 실행 단계별 되감기 (디버거 학습용)

## 운영·품질

- [ ] 리프레시 토큰 + 토큰 폐기 목록
- [ ] 실시간 접속자 집계 (Redis 세션)
- [ ] `audit_logs` 파티셔닝 (월 단위) — 1년 보관 기준
- [ ] E2E 테스트 (Playwright): 로그인 → 미션 실행 → 완료 처리
- [ ] React Compiler 적용률 점검 — 훅 규칙 위반으로 최적화가 빠지는 컴포넌트 찾기
- [ ] 접근성 점검: 블록 워크스페이스 키보드 조작, 스크린리더 안내

## 결정이 필요한 것

- 학생 계정 생성 주체 — 학교 단위 일괄인가, 교사 초대 코드인가
- 개인정보 보관 기간과 파기 절차 (교육기관 대상이면 관련 규정 확인 필요)
- 오프라인/저사양 기기 대응 범위 (학교 태블릿 환경)
